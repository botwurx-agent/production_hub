# Demo media

The demo studio already has thirteen files in storage. This folder is only for
**replacing** them with real work.

Drop a file in using the exact name below, then run `node scripts/demo-media.mjs`
from the repo root. It overwrites in place, so the storage paths the seeded rows
point at never change and nothing else needs touching. Anything not present here
is skipped, so you can replace one file or all of them.

What is in there now was generated on Higgsfield: commercial beverage stills and
three short cuts, kept deliberately consistent so the job reads as one shoot.
Good enough to show, and worth replacing with your own the moment you have
something you would rather put in front of another studio.

- `pack-shot-v1.jpg`, `pack-shot-v2.jpg` — the same bottle, two passes. v2 is

- `frame-01.jpg` … `frame-06.jpg` — six storyboard frames, in story order:
